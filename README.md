# Графики работы

Календарь смен как приложение: свои графики и графики друзей в одном месте.
Открывается с телефона и компьютера, работает офлайн.

- циклы смен `2/2`, `3/3`, `5/2`, `2д2н2в`, дни недели или ручные отметки;
- день и ночь с разным временем смены;
- отпуска и счётчик «сколько осталось до отпуска»;
- экспорт и импорт файла с данными;
- работает без интернета, данные хранятся только на устройстве.

Приложение: [index.html](index.html)

## Установка на iPhone

1. Откройте эту страницу в Safari.
2. «Поделиться» → «На экран «Домой»».

## Установка на Android

1. Откройте страницу в Chrome.
2. Меню ⋮ → «Установить приложение».
